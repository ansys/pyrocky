





:class:`RASimulatorRun`
=======================


.. py:class:: ansys.rocky.app.ra_simulator_run.RASimulatorRun

   Bases: :py:obj:`ansys.rocky.app.ra_grid_process_element.RAGridProcessElementItem`


   
   Rocky PrePost Scripting wrapper for solver settings.

   This wrapper corresponds to the "Solver" item on a project's data tree. Access it from the
   :class:`RAStudy` with:

   .. code-block:: python

       simulator_run = study.GetSimulatorRun()

.. py:method:: SetTargetGpus(gpus: list[int | str]) -> None

   
   On version 27R1 the local execution mode settings are obtained from RASimulatorRun.GetLocalExecutionSettings()
   in contrast with MPI settings that are obtained from RASimulatorSun.GetMpiSettings()

   It will configure the IDs of GPUs that will be used in a local simulation based on the list of IDs or
   names of GPUs passed.

   :param gpus:
       List with IDs or names of GPUs to be used in simulation.
       For example in the name "1 - Geforce GTX 980", the ID is 1 and the name is "1 - Geforce GTX 980".
